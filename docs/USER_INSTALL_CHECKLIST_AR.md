# قائمة تثبيت المستخدم النهائي

هذه القائمة تُستخدم عند تسليم SOM PRO إلى جهاز مستخدم نهائي أو مدرسة.

## قبل التثبيت

- تأكد أن المثبت هو نسخة الإصدار المطلوبة، وليس نسخة قديمة من `release/`.
- تأكد أن Windows محدّث ومسموح له بتثبيت البرامج.
- تأكد أن المنافذ التالية غير مشغولة بواسطة نسخة قديمة:
  - Backend: `4000`
  - License server: `4100`
  - Frontend E2E فقط: `4188`
- إذا كان التشغيل المحلي يعتمد على PostgreSQL وRedis، شغّل:

```bash
npm run local:deps
```

## أثناء التثبيت

1. شغّل ملف المثبت الرسمي فقط.
2. لا تستخدم نسخة قديمة أو ملفًا باسم غير مطابق للإصدار المطلوب.
3. إذا طلب التثبيت صلاحيات المدير، وافق عليه.

## بعد التثبيت

1. افتح البرنامج من الاختصار الرسمي.
2. سجّل الدخول بحساب الترخيص أو بيانات التفعيل المخصصة.
3. تأكد أن صفحة الدخول تظهر بدون أخطاء اتصال.
4. تأكد أن لوحة التحكم والصفحات الأساسية تفتح بشكل طبيعي.

## فحص أول تشغيل

- تظهر شاشة الدخول بدون أخطاء.
- يمكن الدخول بالحساب الصحيح.
- تفتح صفحات الطلاب والمعلمين والجداول والتقارير.
- يظهر الترخيص بحالة صالحة.
- لا تظهر نسخة قديمة من المثبت داخل مجلد التسليم.

## متى نعتبر التثبيت غير ناجح؟

- إذا ظهر أن Backend غير متصل.
- إذا كان المنفذ `4000` أو `4100` مشغولًا بعملية قديمة.
- إذا لم تظهر قاعدة البيانات أو فشل تسجيل الدخول.
- إذا تم تشغيل نسخة قديمة من المثبت بدل النسخة الأخيرة.

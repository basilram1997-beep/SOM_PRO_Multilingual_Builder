# قائمة تثبيت المستخدم النهائي

هذه القائمة تستخدم عند تسليم SOM PRO لجهاز مستخدم نهائي أو مدرسة.

## قبل التثبيت

- تأكد أن نسخة المثبت هي النسخة المطلوبة للتسليم، وليست نسخة قديمة من مجلد `release`.
- تأكد أن Windows محدث وأن المستخدم لديه صلاحية تثبيت البرامج.
- تأكد أن منافذ البرنامج غير مشغولة:
  - Backend: `4000`
  - License server: `4100`
  - Frontend E2E فقط: `4188`
- في التشغيل المحلي، شغل فحص الاعتمادات قبل أول تشغيل:
  - `npm run local:deps`
- تأكد أن PostgreSQL وRedis يعملان إذا كان التشغيل محلياً:
  - PostgreSQL: `5432`
  - Redis: `6379`
  - إذا لم يكونا يعملان، يحاول الأمر الرسمي تشغيلهما عبر Docker Desktop.

## التثبيت

1. شغل ملف المثبت الرسمي فقط.
2. لا تستخدم نسخة داخل مجلد قديم أو اسمها غير مطابق للإصدار المطلوب.
3. بعد انتهاء التثبيت، افتح البرنامج من الاختصار الرسمي.
4. أدخل كود الترخيص أو بيانات الترخيص التي تم تسليمها للمدرسة.
5. سجل الدخول بحساب المدير الأول.

## فحص أول تشغيل

- تظهر شاشة الدخول بدون أخطاء اتصال.
- يدخل المدير إلى لوحة التحكم.
- تفتح صفحات الطلاب والمعلمين والجداول والتقارير.
- يستطيع المدير إنشاء طالب تجريبي ثم حذفه.
- يظهر تقرير الترخيص بحالة صالحة.

## لا تعتبر التثبيت ناجحاً إذا

- ظهرت رسالة أن Backend غير متصل.
- كان المنفذ `4000` أو `4100` مشغولاً بعملية قديمة.
- لم تظهر قاعدة البيانات أو فشل تسجيل الدخول.
- تم تشغيل نسخة قديمة من المثبت بدل النسخة الأخيرة.

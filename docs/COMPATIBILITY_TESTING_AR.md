# اختبار التوافق

يُستخدم هذا الاختبار للتأكد من أن الواجهة تعمل بشكل مقبول على:

- متصفحات سطح المكتب المتاحة محليًا، مثل Chrome وEdge
- أحجام شاشة مختلفة: Desktop وTablet وMobile

## الأمر

```bash
npm run compatibility:test
```

## ماذا يفعل

- يشغّل مسار Playwright الأساسي في أكثر من بيئة عرض.
- يعيد التجربة عبر أكثر من viewport.
- يتحقق من أن الصفحة لا تُحدث overflow أفقيًا أو كسرًا واضحًا في التخطيط.

## مخرجاته

- تقرير JSON داخل `tests/e2e/artifacts`
- تقرير Markdown داخل `tests/e2e/artifacts`

## ملاحظة

هذا يغطي المتصفحات وأحجام الشاشة المتاحة محليًا، لكنه لا يغني عن CI متعدد الأنظمة إذا أردنا تحققًا حقيقيًا على Windows وmacOS وLinux.

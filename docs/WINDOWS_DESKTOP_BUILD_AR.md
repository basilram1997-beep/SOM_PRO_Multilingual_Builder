# بناء تطبيق SOM PRO على Windows

## المتطلبات للتطوير المحلي

- Node.js.
- Docker Desktop عند تشغيل نسخة Trial محلية.
- npm install داخل جذر المشروع.

## بناء نسخة Trial

استخدم سكربت بناء Trial من package.json أو من لوحة التحكم. هذه النسخة محلية وقد تحتاج خدمات محلية.

## بناء نسخة SaaS

استخدم سكربت بناء SaaS مع ضبط API URL وخادم الترخيص. هذه هي النسخة التجارية المقترحة ولا يجب أن تحتاج Docker أو Node على جهاز المدير بعد التثبيت.

## مكان ملف التثبيت

ملفات التثبيت النهائية تظهر داخل مجلد release بعد نجاح البناء.

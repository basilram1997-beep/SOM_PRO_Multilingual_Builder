# حزمة تسليم اختبار الاختراق على Staging

هذه الحزمة تُستخدم قبل تسليم البيئة إلى مختبر أمني خارجي.

## متطلبات البيئة

- بيئة staging منفصلة عن الإنتاج.
- قاعدة بيانات معزولة ومخصصة للاختبار.
- بيانات اختبار أو masked فقط.
- HTTPS فعلي أو طبقة نقل آمنة معتمدة.
- السجلات مفعلة وقابلة للمراجعة.
- نسخة احتياطية جاهزة قبل بدء النافذة.
- عدم استخدام `localhost` للإشارة إلى خدمات staging الخارجية.

## الحسابات المطلوبة

| الدور   | البريد / المعرّف               | كلمة المرور               | ملاحظات                         |
| ------- | ------------------------------ | ------------------------- | ------------------------------- |
| طالب    | `student-test@staging.local`   | `ChangeMe-Student-123!`   | للقراءة فقط على بياناته         |
| ولي أمر | `parent-test@staging.local`    | `ChangeMe-Parent-123!`    | مرتبط بطالب تجريبي              |
| معلم    | `teacher-test@staging.local`   | `ChangeMe-Teacher-123!`   | محدود بصلاحيات التعليم          |
| مربي    | `homeroom-test@staging.local`  | `ChangeMe-Homeroom-123!`  | مرتبط بصف تجريبي                |
| مدير    | `manager-test@staging.local`   | `ChangeMe-Manager-123!`   | لاختبار صلاحيات الإدارة         |
| مطور    | `developer-test@staging.local` | `ChangeMe-Developer-123!` | يُستخدم فقط إذا كان داخل النطاق |

## ما يجب تسليمه للمختبر

- رابط staging.
- قائمة الحسابات.
- تحديد واضح للنطاق وما هو خارج النطاق.
- نافذة الفحص.
- نقطة اتصال مباشرة.
- قالب التقرير النهائي.
- طريقة استرجاع أو نسخة احتياطية جاهزة.

## النطاق المطلوب

- واجهة الويب على staging.
- المسارات الحساسة للمصادقة والصلاحيات.
- التقارير والتصدير.
- الرفع والملفات المؤقتة إذا كانت موجودة.
- الترخيص.
- النسخ الاحتياطي والاسترجاع.
- مسارات الإدارة الحساسة.

## قبل التسليم

- شغّل `npm run security:pentest:prep`.
- شغّل `npm run staging:check` إذا كانت ملفات staging جاهزة.
- شغّل `npm run staging:smoke` عند توفر الروابط الحقيقية.
- تأكد من أن الحسابات التجريبية تعمل.
- تأكد من أن النطاق مكتوب بوضوح وأنه لا توجد نقاط رمادية.

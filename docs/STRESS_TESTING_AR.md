# اختبار الإجهاد

هذا الاختبار يدفع النظام فوق السعة المعتادة ثم يتحقق من أنه يعود للعمل بعد الانقطاع أو التراجع في الأداء.

## الأمر

```bash
npm run stress:test
```

## ماذا يفعل

- يشغّل حملًا أعلى من الحمل العادي على تسجيل الدخول والدرجات والحضور والتقارير.
- يفعل انقطاعًا مقصودًا في منتصف التشغيل عند الحاجة.
- يعيد تشغيل backend بعد الانقطاع.
- يتحقق من عودة:
  - `/health`
  - تسجيل الدخول
  - `classes`
  - `reports`
  - `students`

## المخرجات

- تقرير ضغط داخل `tests/stress/artifacts`
- تقرير تعافٍ داخل `tests/stress/artifacts`

## ملاحظة

هذا الاختبار مفيد لكشف نقطة الانهيار وسلوك التعافي، لكنه قد يترك آثارًا تشغيلية مؤقتة أثناء التنفيذ، لذلك يفضّل تشغيله في نافذة مخصصة أو على staging.

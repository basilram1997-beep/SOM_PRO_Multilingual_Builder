# Edge Cases لاختبار الاختراق

هذا المستند يجمع الحالات الحدّية التي يجب تضمينها في اختبار الاختراق الخارجي لنظام SOM PRO.

## المصادقة والجلسات

- تبديل الدور داخل نفس الجلسة واختبار بقاء الصلاحيات القديمة.
- استخدام جلسة منتهية أو توكن قديم للوصول إلى endpoint حساس.
- تكرار تسجيل الدخول والخروج بسرعة والتأكد من عدم بقاء أثر يسمح بالوصول.
- اختبار سلوك "تذكرني" والبيانات المخزنة في المتصفح بعد تسجيل الخروج.

## العزل والصلاحيات

- تعديل `schoolId` أو `classId` أو `studentId` في الطلب مباشرة.
- الوصول إلى بيانات مدرسة أخرى عبر تبديل المعرفات فقط.
- محاولة الوصول إلى سجل صف أو مادة أو طالب خارج النطاق المصرح.
- اختبار endpoints الإدارية بحسابات أدوار أدنى.

## الكتابة والتكرار

- إعادة إرسال نفس طلب الحضور أو التصدير بسرعة عدة مرات.
- إرسال نفس payload بتوقيت متقارب مع اختلاف بسيط في الحقول.
- التحقق من عدم إنشاء سجلات مكررة عند إعادة المحاولة.
- اختبار ما يحدث عند انقطاع الشبكة أثناء الكتابة ثم إعادة الإرسال.

## البيانات والحقول

- قيم فارغة جداً أو طويلة جداً.
- سلاسل فيها أحرف RTL/LTR مختلطة.
- أرقام وهواتف ومعرّفات بصيغ غير متوقعة.
- قيم JSON غير متوافقة أو ناقصة في الحقول التي تتوقع بنية محددة.

## الملفات والرفع

- ملف بامتداد صحيح لكن بمحتوى غير صحيح.
- ملف مضغوط أو ثنائي يسمى كأنه PDF أو صورة.
- تجاوزات في اسم الملف أو المسار أو الترميز.
- إعادة رفع نفس الملف بعد تعديله جزئياً.

## التقارير والتصدير

- فتح export أو report لا يملكه الحساب الحالي.
- تعديل بارامترات التقرير يدوياً في الرابط أو الطلب.
- الوصول إلى export قديم بعد انتهاء صلاحيته.
- اختبار ما إذا كانت التقارير تكشف بيانات مرتبطة بمدرسة أخرى.

## الترخيص والتحديث

- استخدام license قديم أو منتهٍ أو من جهاز مختلف.
- إعادة تشغيل الجلسة بعد تسجيل الخروج ثم محاولة استكمال نفس المسار.
- اختبار التحديث أثناء وجود عمليات جارية.

## الشبكة والاعتمادية

- توقف جزئي للخدمة أثناء القراءة.
- عودة الخدمة بعد انقطاع قصير.
- ضغط قصير على rate limit ثم الرجوع للوضع الطبيعي.
- تأخر استجابة backend مع استمرار طلبات الواجهة.

## مخرجات المختبر

- تسجيل واضح لكل حالة حدّية تم اختبارها.
- توضيح هل السلوك مقبول، مرفوض، أو يحتاج إصلاح.
- ربط كل حالة بملف إعادة الإنتاج أو اللقطة أو الطلب/الرد.

# قائمة تحقق المتصفح لـ SOM PRO

هذه القائمة تُستخدم كتحقق عملي قبل التسليم التجاري، حتى لا تبقى عبارة "browser flows" وصفًا عامًا فقط.

## المتصفحات المطلوبة

- Chrome
- Edge
- Firefox
- Safari عند الإمكان

## تدفقات يجب اختبارها

| التدفق              | ما الذي يجب أن يعمل                                        |
| ------------------- | ---------------------------------------------------------- |
| فتح الصفحة الرئيسية | تحميل الواجهة دون أخطاء، وظهور القائمة الجانبية والعنوان   |
| تسجيل الدخول        | قبول البيانات الصحيحة، ورفض الخاطئة برسالة واضحة           |
| تسجيل الخروج        | العودة إلى شاشة الدخول دون بقاء بيانات حساسة               |
| تغيير اللغة         | تبديل العربية / English / עברית بوضوح                      |
| القائمة الجانبية    | التنقل بين الصفحات دون كسر الترتيب أو إخفاء العناصر المهمة |
| البرنامج اليومي     | تحميل الجدول، الحفظ، الاستبدال، والأرشفة                   |
| الشهادات            | فتح الصفحة، معاينة البيانات، والتصدير من نفس المصدر        |
| إدخال العلامات      | اختيار الصف والمادة، الحفظ، وربط البيانات بالشهادة         |
| الترخيص             | عرض الحالة، التفعيل، والتنبيه عند المشاكل                  |
| الوضع دون اتصال     | إظهار رسالة مفهومة ومسار استعادة واضح                      |

## حالات يجب مراقبتها

- لا يوجد نص مكسور أو mojibake.
- لا يوجد تداخل بين النصوص والبطاقات.
- لا تبقى الصفحة في حالة تحميل بلا نهاية.
- لا يظهر للمستخدم خطأ تقني خام.
- لا تختفي صلاحيات الدور أو تتغير أثناء التنقل.
- لا تُحفظ قيم حساسة في المتصفح.

## ملاحظة

هذه القائمة لا تستبدل الاختبار اليدوي، لكنها تجعل "browser flows" بندًا واضحًا ومحدّدًا بدل أن يبقى ملاحظة عامة.

# استراتيجية Playwright / Cypress

هذه الوثيقة تشرح مسار اختبارات المتصفح الفعلية في SOM PRO.  
المسار الحالي المعتمد هو **Playwright**، بينما **Cypress** يبقى خيارًا لاحقًا إذا احتجنا توسعة مختلفة.

## الحالة الحالية

- يوجد مسار Playwright browser E2E فعلي داخل المشروع.
- يمكن تشغيله عبر `npm run test:e2e:browser`.
- يمكن تشغيله بوضع مرئي للمراجعة عبر `npm run test:e2e:browser:headed`.
- يمكن تثبيت متطلبات المتصفح عبر `npm run test:e2e:browser:install`.
- يجب تشغيله على جهاز يحتوي على متصفح مدعوم وخدمة staging/خدمات محلية جاهزة.

## ما الذي ينبغي أن يغطيه المسار الموسع

| الأولوية | التدفق                | الهدف                                                |
| -------- | --------------------- | ---------------------------------------------------- |
| P0       | تسجيل الدخول والترخيص | التأكد أن الجلسة والترخيص يفتحان التطبيق بشكل صحيح   |
| P0       | التنقل الأساسي        | الرئيسية، ملفات المعلمين، البرنامج اليومي، الإعدادات |
| P1       | الحضور والغياب        | تسجيل الحالة وحفظها وتصديرها                         |
| P1       | إدخال العلامات        | اختيار الصف، المادة، الحفظ، وربط الشهادات            |
| P1       | الشهادات              | المعاينة، التصدير، والطباعة                          |
| P1       | الأرشيف               | حفظ اليوم، عرض اليوم المحفوظ، والتصدير               |
| P2       | لوحة العمليات         | عرض التصديرات، النسخ الاحتياطية، وسجل التدقيق        |

## قواعد التشغيل

- لا نعتبر المسار ناجحًا إذا كان يعتمد على حالة عشوائية في قاعدة البيانات.
- يجب تجهيز بيانات اختبار ثابتة قبل التشغيل.
- يجب أن يكون هناك Backend وLicense Server جاهزان قبل بدء الاختبار.
- أي خطأ في نص عربي/عبري أو أي mojibake يجب إصلاحه في نفس السلسلة، وليس تأجيله.

## ما لا نريده

- لا نريد تكرار unit tests داخل Playwright.
- لا نريد اختبار كل زر بلا قيمة.
- لا نريد اختبارات UI هشة تعتمد على نصوص مؤقتة أو بيانات عشوائية.

## التوسعة التالية الطبيعية

إذا أردنا توسيع المسار لاحقًا، فالأولوية تكون:

1. الشهادات.
2. إدخال العلامات.
3. الحضور والغياب.
4. الأرشيف.
5. صفحة العمليات الإدارية.

## الخلاصة

Playwright هو المسار الفعلي المعتمد الآن لاختبارات المتصفح، ويجب أن يُشغَّل على بيئة مناسبة مع متصفح حقيقي.  
Cypress يمكن إضافته لاحقًا، لكنه ليس شرطًا الآن ما دام Playwright يغطي التدفقات الأساسية بشكل متزايد.

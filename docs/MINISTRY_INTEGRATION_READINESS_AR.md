# جاهزية الربط مع أنظمة وزارة التربية

هذا المستند يوضح أين يقف SOM PRO الآن من ناحية الجاهزية المعمارية للربط مع أنظمة وزارة التربية، وما الذي ما زال يحتاج تكاملًا خارجيًا فعليًا.

## ما هو جاهز الآن

- Backend مركزي فعلي.
- PostgreSQL معزول حسب المدرسة.
- كل الكيانات الأساسية مرتبطة بـ `schoolId`.
- صلاحيات دقيقة على مستوى الأدوار والمسارات.
- `Audit Log` على العمليات الحساسة.
- تقارير تصدير ومخرجات قابلة للحفظ.
- عزل متعدد المدارس في القراءة والكتابة.

## ما الذي يعنيه "جاهز معماريًا"

- يمكن إضافة تكامل خارجي لاحقًا دون إعادة بناء الأساس.
- يمكن ربط بيانات المدرسة عبر عقود API محددة.
- يمكن تقييد أي تبادل بيانات عبر صلاحيات وسجلات تدقيق.
- يمكن وضع وسيط تكامل منفصل بدل خلط التكامل مع المنطق اليومي.

## ما الذي لا يزال غير متصل فعليًا

- لا يوجد الآن اتصال مباشر بواجهات وزارة التربية.
- لا توجد مزامنة فعلية للطلاب أو الصفوف أو النتائج مع طرف خارجي.
- لا يوجد معرّف وطني/رسمي مفعّل كجزء من مسار تشغيل الوزارة.
- لا توجد موافقات تشغيلية خارجية أو مفاتيح تبادل معتمدة.

## متطلبات التكامل المستقبلي

1. تحديد الطرف الحكومي المصرح.
2. تحديد العقود والحقول المسموح تبادلها.
3. ربط تكامل منفصل مع سجلات تدقيق إضافية.
4. إضافة مفاتيح بيئة مستقلة للتكامل.
5. اختبار العزل بين المدارس قبل أي مزامنة خارجية.
6. منع أي إرسال بيانات خارجية دون موافقة صريحة.

## الخلاصة

SOM PRO الآن **جاهز معماريًا** ليُربط لاحقًا بأنظمة الوزارة، لكنه **غير متصل فعليًا بعد**.  
هذا جيد من ناحية البناء، لأننا لا نخلط منطق المدرسة اليومي مع التكامل الخارجي قبل أن تصبح الموافقات والعقود واضحة.

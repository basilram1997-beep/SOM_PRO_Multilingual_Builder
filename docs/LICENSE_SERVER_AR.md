# خادم الترخيص SOM PRO

هذا الملف يشرح الدور العملي لخادم الترخيص بشكل مختصر وواضح.

## ماذا يفعل؟

- إصدار الترخيص لكل مدرسة.
- تفعيل الأجهزة لأول مرة.
- متابعة عدد الأجهزة المفعلة.
- تعليق الترخيص أو إلغاؤه من لوحة المالك.

## كيف يعمل في الوضع المحلي؟

1. شغّل خادم الترخيص من لوحة التحكم أو من أمر التشغيل المخصص.
2. افتح لوحة المالك على `http://localhost:4100` أثناء التطوير المحلي.
3. لا تضع رموز المالك أو أسرار الإنتاج داخل الواجهة أو تطبيق سطح المكتب.

## ملاحظات مهمة

- نسخة SaaS يجب أن تستخدم عنوان خادم ترخيص حقيقي عبر HTTPS.
- الواجهة الأمامية وتطبيق سطح المكتب يرسلان فقط بيانات الترخيص والجهاز، وليس أي أسرار إدارية.
- هذا الملف توثيقي فقط، وليس ملف إعدادات.

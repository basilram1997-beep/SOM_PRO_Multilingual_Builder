# دليل مبسط جدًا لغير المبرمج

هذا الملف يشرح فقط أين تبدأ وماذا تضغط.

## ابدأ من هنا

افتح:

```text
START_HERE_WINDOWS.cmd
```

ثم اختر العملية المناسبة من القائمة.

## الملفات المهمة

- `scripts/windows/01_CHECK_SYSTEM_WINDOWS.cmd` لفحص الجهاز.
- `scripts/windows/02_RUN_DESKTOP_TEST_WINDOWS.cmd` لتجربة سطح المكتب.
- `scripts/windows/03_RUN_WEB_LOCAL_WINDOWS.cmd` لتشغيل الويب محليًا.
- `scripts/windows/04_BUILD_SOM_PRO_SETUP_EXE_WINDOWS.cmd` لبناء ملف التثبيت.

## ماذا أحتاج على جهازي؟

- Node.js
- Docker Desktop عند الاستخدام المحلي
- اتصال إنترنت إذا كنت ستجرب النسخة SaaS أو أول تفعيل

## إذا لم يعمل المشروع

ارجع إلى:

1. `HANDOFF.md`
2. `README.md`
3. `KNOWN_ISSUES.md`

هذه النسخة لا تعني أن كل شيء production نهائي.  
هي نسخة جاهزة للفهم والتجربة والتطوير المنظم.

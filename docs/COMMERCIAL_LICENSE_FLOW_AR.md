# تدفق الترخيص التجاري في SOM PRO

## الفكرة العامة

في المسار التجاري المعتمد، SOM PRO يعمل بنظام SaaS مركزي:

- قاعدة البيانات والخادم وخادم الترخيص تعمل على سيرفر المالك.
- نسخة Desktop عند المدرسة هي واجهة تتصل بالسيرفر.
- مدير المدرسة يحتاج إنترنت، كود ترخيص، وحساب مدرسة.
- لا يحتاج Docker أو Node أو PostgreSQL محلي.

## كيف يحصل المدير على البرنامج؟

1. المالك ينشئ مدرسة من لوحة المالك.
2. المالك يصدر License Key أو كود ترخيص قصير للمدرسة.
3. الترخيص يحتوي على اسم المدرسة، رقم المؤسسة، نوع الخطة، تاريخ الانتهاء، وعدد الأجهزة المسموح.
4. المالك يرسل للمدير ملف التثبيت وكود الترخيص وبيانات الدخول الأولية.

## ماذا يحدث عند التفعيل؟

عند أول تشغيل أو عند إدخال كود الترخيص:

1. تطبيق Desktop يولد `deviceId` ثابتًا للجهاز من installationId محلي.
2. الواجهة ترسل `licenseKey`, `deviceId`, `deviceName`, `appVersion`, و `platform` إلى backend.
3. backend يرسلها إلى License Server المركزي.
4. License Server يتحقق من:
   - الترخيص موجود.
   - الترخيص غير منتهي.
   - الترخيص غير معلق أو ملغى.
   - الجهاز مفعل سابقًا أو عدد الأجهزة لم يتجاوز `maxDevices`.
5. إذا كل شيء صحيح، يتم تسجيل الجهاز ضمن أجهزة الترخيص.

## ماذا يحدث إذا وزع المدير الملف لمدرسة أخرى؟

نسخ ملف التثبيت وحده لا يكفي. المدرسة الأخرى ستحتاج كود ترخيص صحيح. وإذا استخدمت نفس الكود:

- إذا تجاوزت عدد الأجهزة، يرفض License Server التفعيل.
- إذا كانت بيانات المدرسة لا تطابق الترخيص في مرحلة التثبيت، يمكن رفض العملية.
- إذا أوقف المالك الترخيص، يصبح غير قابل للاستخدام.

## منع عدد الأجهزة الزائد

كل ترخيص يحتوي على `maxDevices`. عند تفعيل جهاز جديد:

- إذا الجهاز مسجل سابقًا، يسمح له.
- إذا جهاز جديد والعدد تحت الحد، يتم تسجيله.
- إذا جهاز جديد والعدد وصل الحد، يرجع الخطأ `MAX_DEVICES_REACHED`.

## إيقاف ترخيص أو جهاز

من License Server يمكن للمالك:

- إنشاء ترخيص.
- تعليق ترخيص.
- إلغاء ترخيص.
- تجديد تاريخ الانتهاء.
- تغيير `maxDevices`.
- عرض الأجهزة المفعلة.
- تعطيل جهاز محدد.

## Grace Period

إذا انقطع الاتصال بخادم الترخيص مؤقتًا:

- إذا كان هناك تحقق ناجح سابق، يسمح SOM PRO بالعمل مؤقتًا لمدة افتراضية 3 أيام.
- بعد انتهاء المدة، يمنع التعديل حتى يعود الاتصال ويتم التحقق.
- لا يتم حذف بيانات المدرسة.

يمكن ضبط المدة عبر:

```text
SOM_PRO_LICENSE_GRACE_DAYS=3
```

## أين تحفظ بيانات التفعيل؟

- في License Server: داخل `apps/license-server/data/licenses.json` في وضع التطوير المحلي.
- في backend: داخل جدول `LicenseActivation` لحالة ترخيص المدرسة محليًا داخل النظام.
- في Desktop: فقط `deviceId` محلي غير حساس داخل مجلد بيانات التطبيق.

## الأسرار

لا يجب وضع أسرار المالك في frontend أو desktop. الأسرار مثل:

- `LICENSE_ADMIN_TOKEN`
- `SOM_PRO_LICENSE_SECRET`
- `SOM_PRO_AUTH_SECRET`

تبقى في server env فقط.

## المتبقي قبل الإنتاج الحقيقي

- نقل License Server من JSON file إلى قاعدة بيانات إنتاجية.
- تشغيله خلف HTTPS ودومين حقيقي.
- إضافة rate limiting و audit log مفصل لعمليات المالك.
- توقيع Windows installer.
- اختبار clean install على جهاز جديد.

# اختبار سهولة الاستخدام

هذا الاختبار يقيس ما إذا كانت الواجهة سهلة الفهم والتنقل للمستخدم البشري، وليس فقط ما إذا كانت تعمل تقنيًا.

## الأمر

```bash
npm run test:e2e:browser:usability
```

## ما الذي يغطيه

- وضوح شاشة الدخول.
- تبديل اللغة بين العربية والإنجليزية والعبرية.
- ترتيب التنقل بالكيبورد داخل شاشة الدخول.
- سهولة الوصول إلى صفحات `teachers` و`students` و`reports` بعد تسجيل الدخول.
- بقاء التخطيط دون overflow أفقي على desktop وmobile.
- انتقال التركيز إلى منطقة المحتوى الرئيسية بعد التنقل، حتى لا يضيع المستخدم.

## مخرجات النجاح

- التقرير ينجح على مقاسي شاشة:
  - desktop
  - mobile
- وتبقى النصوص الأساسية والانتقال واللغة واضحة.

## ملاحظة

هذا اختبار آلي جيد لالتقاط مشاكل السلاسة والوضوح المبكرة، لكنه لا يغني عن جلسة UAT بشرية مع مستخدمين حقيقيين قبل الإطلاق التجاري النهائي.

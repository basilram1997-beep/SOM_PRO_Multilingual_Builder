# برامج المعلمين اليومية

هذه الميزة تضيف برنامجًا خاصًا لكل معلم بعد توليد البرنامج اليومي.

## الفكرة

بدل أن يبحث المعلم عن حصته داخل جدول كبير يحتوي كل الصفوف، يستطيع المدير توليد برامج مصغرة للمعلمين بضغطة زر.

## متى يتم توليدها؟

لا يتم توليد برامج المعلمين تلقائيًا. تظهر تحت صفحة **الجداول والبدائل**، ولا تُحسب إلا عندما يضغط المدير زر:

```text
توليد برامج المعلمين
```

## ماذا يظهر في برنامج كل معلم؟

- حصصه الأصلية من البرنامج الثابت.
- الاستبدالات التي كُلّف بها بعد الغياب أو التأخر أو المغادرة.
- حالة المعلم إن كان غائبًا أو متأخرًا أو مغادرًا.
- عدد الحصص الأصلية.
- عدد الاستبدالات.
- مجموع الحصص الفعلية لذلك اليوم.

## هل تعمل إذا لم يكن هناك غياب؟

نعم. إذا لم يكن هناك غياب أو تأخر، يستطيع المدير توليد البرنامج اليومي العادي، ثم توليد برامج المعلمين. عندها يظهر لكل معلم حصصه الأصلية فقط.

## أين المنطق؟

المنطق موجود في الباك إند داخل:

```text
apps/backend/src/services/teacherDailyPrograms.ts
```

والواجهة تطلب النتيجة عبر:

```text
POST /api/daily/:date/teacher-programs/generate
```

بهذا لا تصبح الواجهة مسؤولة عن حساب برامج المعلمين، بل تعرض فقط ما يرسله الباك إند.

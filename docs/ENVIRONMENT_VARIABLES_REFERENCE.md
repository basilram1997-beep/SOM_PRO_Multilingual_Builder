# Environment Variables Reference

Last reviewed: 2026-09-06

This is the canonical handoff reference for SOM PRO runtime, deployment, security, testing, and evidence environment variables.

## Rules

- Do not commit real `.env` files.
- Use `.env.example`, `.env.staging.example`, and `.env.production.example` only as templates.
- Put production secrets in a secret manager, Docker secrets, CI secrets, or host-level protected environment variables.
- Treat every URL with embedded credentials as a secret.
- Values marked `Production-safe: No` are acceptable only for local development or isolated test runs.
- Values marked `Required in production` must be configured before a production or Ministry-facing staging handoff.

## Runtime Core

| Variable | Required / Optional | Default / Source | Production-safe | Notes |
| --- | --- | --- | --- | --- |
| `NODE_ENV` | Required in production | `development` if omitted by Node tooling | Yes, when `production` | Must be `production` for production deployments. |
| `APP_ENV` | Optional | Deployment-specific | Yes | Use `local`, `staging`, or `production` for diagnostics and evidence. |
| `APP_DEBUG` | Optional | `false` | No, if `true` | Keep disabled in production. |
| `PORT` | Optional | Backend default port | Yes | Backend HTTP port, usually behind Nginx. |
| `DATABASE_URL` | Required | Local default: `postgresql://som_user:som_password@127.0.0.1:5432/som?schema=public` | No, if local/default or contains committed credentials | Required by Prisma, migrations, backend, and license server DB flow. |
| `REDIS_URL` | Required for multi-instance production | Local default: `redis://127.0.0.1:6379` | No, if unauthenticated in production | Required for distributed request protections and shared runtime state. |
| `CORS_ORIGIN` | Required when API is cross-origin | Deployment origin | Yes | Prefer same-origin `/api` routing when possible. |
| `SOM_RUNTIME_MODE` | Optional | App-specific default | Yes | Use to distinguish trial/SaaS/local modes when configured. |
| `SOM_API_URL` | Optional | Same-origin or deployment-specific | Yes | Runtime API URL for desktop/mobile flows. |
| `VITE_API_URL` | Required for frontend builds when not same-origin | `/api` in production examples | Yes | Must not point to localhost in staging/production builds. |
| `SOM_PRO_APP_URL` | Required for SaaS/staging evidence | Public HTTPS app URL | Yes | Must be HTTPS for external evidence. |
| `SOM_LICENSE_SERVER_URL` | Optional legacy/alias | Prefer `SOM_PRO_LICENSE_SERVER_URL` | Yes | Keep only if a runtime path still consumes it. |
| `SOM_PRO_LICENSE_SERVER_URL` | Required for SaaS/central license enforcement | `http://localhost:4100` in local setup | No, if localhost in production | Must be HTTPS or same private network service in production. |
| `SOM_PRO_REQUIRE_CENTRAL_LICENSE` | Required for SaaS policy | `false` unless explicitly enabled | Yes | Set `true` where central enforcement is mandatory. |
| `SOM_PRO_LICENSE_GRACE_DAYS` | Optional | Product policy default | Yes | Defines central outage grace behavior. |
| `SOM_PRO_LICENSE_TIMEOUT_MS` | Optional | Product policy default | Yes | Keep low enough to avoid per-request latency spikes. |

## Security And Identity

| Variable | Required / Optional | Default / Source | Production-safe | Notes |
| --- | --- | --- | --- | --- |
| `SOM_PRO_LICENSE_SECRET` | Required | Generated by setup for local | No, if default/generated value is shared | Rotate before external handoff if exposed. |
| `SOM_PRO_AUTH_SECRET` | Required | Generated by setup for local | No, if default/generated value is shared | Used for auth/session integrity. |
| `JWT_SECRET` | Required if JWT path is enabled | Secret manager | No, if placeholder | Must be high entropy. |
| `LICENSE_ADMIN_TOKEN` | Required for license admin APIs | Secret manager | No, if placeholder | Must not be sent to frontend clients. |
| `SOM_PRO_ADMIN_EMAIL` | Required for bootstrap/local install | `admin@sompro.local` in local setup | No, if default in production | Replace for real deployments. |
| `SOM_PRO_ADMIN_PASSWORD` | Required for bootstrap/local install | Generated by setup when missing | No | Temporary bootstrap credential; rotate after first login. |
| `SOM_PRO_AUTH_INACTIVITY_TIMEOUT_SECONDS` | Optional | Product security default | Yes | Shorter values improve account safety. |
| `SOM_PRO_AUTH_TOKEN_TTL_SECONDS` | Optional | Product security default | Yes | Align with Ministry/security policy. |
| `SOM_PRO_MFA_ENCRYPTION_KEY` | Required when MFA recovery codes are persisted encrypted | Secret manager/KMS | No, if missing or placeholder | Must be rotated through controlled procedure. |
| `SOM_TRUST_PROXY` | Required behind reverse proxy | `false` unless configured | Yes, when proxy boundary is trusted | Enable only behind trusted Nginx/Cloudflare. |
| `TRUST_PROXY` | Optional alias | Prefer `SOM_TRUST_PROXY` | Yes, when proxy boundary is trusted | Keep consistent with backend config. |

## Database, Redis, Storage, And Backups

| Variable | Required / Optional | Default / Source | Production-safe | Notes |
| --- | --- | --- | --- | --- |
| `POSTGRES_DB` | Required for Docker production | `som` in local compose | Yes | Must match `DATABASE_URL`. |
| `POSTGRES_USER` | Required for Docker production | `som_user` in local compose | Yes | Use least-privilege DB user where possible. |
| `POSTGRES_PASSWORD` | Required for Docker production | Local compose uses `som_password` | No, if default | Must come from `.env.production` or secret manager. |
| `REDIS_PASSWORD` | Required for production Redis | None locally | No, if empty in production | Production compose requires it. |
| `SOM_STORAGE_PATH` | Required when file uploads/artifacts are enabled | Deployment-specific | Yes | Must be persistent and backed up. |
| `SOM_LICENSE_DATA_DIR` | Optional legacy/file-store path | Deployment-specific | No, if used as primary production store | Prefer DB/Redis-backed license server flow. |
| `SOM_BACKUP_DIR` | Required for backup jobs | Deployment-specific | Yes | Must not be inside public web root. |
| `SOM_BACKUP_PASSPHRASE` | Required unless `_FILE` or encryption key is used | Secret manager | No | Prefer `SOM_BACKUP_PASSPHRASE_FILE` in Docker/production. |
| `SOM_BACKUP_PASSPHRASE_FILE` | Preferred in production | `/run/secrets/som_backup_passphrase` in examples | Yes | Stores a path, not the passphrase itself. |
| `SOM_BACKUP_ENCRYPTION_KEY` | Optional alternative | Secret manager/KMS | No | Use only with documented rotation. |
| `SOM_BACKUP_RPO_MINUTES` | Required for production evidence | Business continuity target | Yes | Used in readiness/evidence checks. |
| `SOM_BACKUP_RTO_MINUTES` | Required for production evidence | Business continuity target | Yes | Used in readiness/evidence checks. |
| `SOM_PG_DUMP_PATH` | Optional | `pg_dump` from PATH/container | Yes | Set when the binary is not on PATH. |
| `ALLOW_PLAINTEXT_RESTORE` | Optional emergency/test flag | `false` | No, if `true` | Never enable for normal production restore flows. |

## License Server

| --- | --- | --- | --- | --- |
| `LICENSE_PORT` | Optional | `4100` | Yes | Internal service port. |

| `LICENSE_REDIS_URL` | Required when `LICENSE_REQUEST_BACKING=redis` | Can reuse `REDIS_URL` | No, if unauthenticated in production | Must point to shared Redis. |
| `LICENSE_CORS_ORIGIN` | Required for cross-origin admin/client calls | Deployment origin | Yes | Prefer same-origin/proxy routing. |
| `LICENSE_ADMIN_RATE_LIMIT` | Optional | Policy default | Yes | Tune separately from client limits. |
| `LICENSE_CLIENT_RATE_LIMIT` | Optional | Policy default | Yes | Protect activation/status endpoints. |
| `LICENSE_GENERAL_RATE_LIMIT` | Optional | Policy default | Yes | Applies to general license-server requests. |
| `LICENSE_MAX_BODY_BYTES` | Optional | Policy default | Yes | Keep constrained to reduce abuse risk. |
| `LICENSE_RESET_TOKEN_TTL_MS` | Optional | Policy default | Yes | Time-box admin recovery tokens. |
| `LICENSE_REQUEST_NONCE_TTL_MS` | Optional | Policy default | Yes | Replay protection TTL. |
| `LICENSE_REQUIRE_CLIENT_NONCE` | Required in production | `true` in hardened production | Yes, when `true` | Do not disable in public production. |
| `PUBLIC_BASE_URL` | Required for public links/emails | Public HTTPS base URL | Yes | Must be HTTPS in staging/production. |

## Production Minimum

For a production or Ministry-facing staging environment, configure at least:

- `NODE_ENV=production`
- `APP_ENV=production` or `APP_ENV=staging`
- `DATABASE_URL`
- `REDIS_URL`
- `CORS_ORIGIN` when not same-origin
- `VITE_API_URL=/api` or the approved HTTPS API URL
- `SOM_PRO_APP_URL`
- `SOM_PRO_LICENSE_SERVER_URL`
- `SOM_PRO_LICENSE_SECRET`
- `SOM_PRO_AUTH_SECRET`
- `JWT_SECRET`
- `LICENSE_ADMIN_TOKEN`
- `SOM_PRO_MFA_ENCRYPTION_KEY`
- `POSTGRES_PASSWORD`
- `REDIS_PASSWORD`
- `SOM_STORAGE_PATH`
- `SOM_BACKUP_DIR`
- `SOM_BACKUP_PASSPHRASE_FILE` or equivalent KMS-backed materialization
- `SOM_BACKUP_RPO_MINUTES`
- `SOM_BACKUP_RTO_MINUTES`
- `LICENSE_REQUEST_BACKING=redis`
- `LICENSE_REDIS_URL`
- `LICENSE_REQUIRE_CLIENT_NONCE=true`
- `PUBLIC_BASE_URL`
- `SOM_FILE_UPLOAD_SCANNING_ENABLED=true`
- `SOM_FILE_UPLOAD_SCANNER_URL`

## Local Verification Commands

```bash
npm run test:db:prepare
npm run test:db:verify
npm test
```

`npm run test:db:verify` is the required command for closing database-related delivery evidence. It runs the database-critical backend suite and the license-server database flow on PostgreSQL, Redis, and Docker, then writes `docs/test-reports/database-verification-latest.md`.

# Decision Log Template

Use this template to record the operational decisions that affect privacy, security, compliance, or release readiness.
It is the shared record for compliance, security, or release readiness decisions.

## Why this exists

The decision log keeps compliance decisions from becoming informal or forgotten.

## Template

| Field                  | Value               |
| ---------------------- | ------------------- |
| Date                   | YYYY-MM-DD          |
| Decision title         |                     |
| Decision owner         |                     |
| Scope                  |                     |
| Risk level             | Low / Medium / High |
| Related policy         |                     |
| Required approval      |                     |
| Approved by            |                     |
| Summary                |                     |
| Operational impact     |                     |
| Follow-up action       |                     |
| Re-test or review date |                     |

## Typical entries

- DPA reviewed before deployment.
- Retention period approved.
- Backup restore policy changed.
- Export format approved.
- Third-party integration approved.
- External review completed.

## Storage rule

- Keep the log in a shared operational folder or repository location that the vendor security owner can review.
- Do not store the decision only in chat or email.

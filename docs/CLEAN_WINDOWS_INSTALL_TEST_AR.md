# اختبار تثبيت Windows النظيف

هذه المذكرة تستخدم أثناء التأكد من أن النسخة تعمل على جهاز Windows جديد أو نظيف:

1. إزالة أي بقايا قديمة من الإصدارات السابقة.
2. تثبيت البرنامج من installer النهائي.
3. تشغيله دون Node.js أو Docker إذا كان هذا هو سيناريو التوزيع.
4. تسجيل الدخول، فتح الصفحات الأساسية، والتأكد من عدم ظهور أخطاء تشغيل.

الملاحظة الأهم:

- إذا احتاج التشغيل إلى Docker أو قاعدة محلية، فيجب أن يذكر ذلك بوضوح في دليل التسليم.

# Student Media Capture Policy

## Status

- Photo capture: disabled by default.
- Video recording: disabled by default.
- Audio recording: disabled by default.
- No student media capture feature is included in the current MVP.

## Policy

- The product must not expose photo, video, or audio recording of students as a normal school workflow.
- Any future media capture feature would require explicit school approval, parental consent where applicable, and a documented retention/deletion policy.
- Media capture must not be used to bypass normal privacy controls or export rules.
- If such a feature is ever introduced, it must be separated from the pedagogical core and treated as a high-sensitivity feature.

## Operational rule

- The UI should not present student media capture controls unless the feature is explicitly enabled by configuration and approval.
- Support staff must not enable media capture without approval from the school or authority contact.

## Notes

- This document exists to make the default “no capture” stance explicit for sale, review, and handoff.

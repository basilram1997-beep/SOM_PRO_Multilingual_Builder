# دليل بناء SOM PRO Setup.exe على Windows

## قبل البدء

تأكد من وجود:

1. Node.js LTS.
2. Docker Desktop إذا كنت ستبني أو تختبر النسخة المحلية.
3. Git اختياري.

## الخطوات المختصرة

1. افتح المجلد الرئيسي للمشروع.
2. شغّل `START_HERE_WINDOWS.cmd`.
3. اختر الفحص أولًا إذا كنت تريد التأكد من جاهزية الجهاز.
4. اختر بناء نسخة التثبيت عندما تكون البيئة جاهزة.

## أين يظهر ملف التثبيت؟

عادة يظهر ملف التثبيت داخل:

```text
apps\desktop\release\
```

وقد يختلف الاسم قليلًا حسب رقم الإصدار ونوع النسخة.

# Screenshot Checklist

Capture these screens for Google Play and App Store review.

## Required screenshots

1. Login screen
2. Main dashboard / home
3. Lessons / homework / exams page
4. Attendance page
5. Behavior page
6. Grades page
7. Certificates page
8. Timetable / daily program page
9. Reports / archive page

## Recommended capture rules

- Use the final Arabic UI first.
- Add English screenshots only if the store listing will be localized.
- Hide any real personal data.
- Avoid showing test credentials or internal admin tokens.
- Use consistent device sizes.
- Capture at least one phone-sized set for mobile store listing.

# Submission Checklist

## Before upload

- [ ] Verify the support email, website URL, and privacy policy URL are correct
- [ ] Confirm the final screenshot set in `store/final-screenshots/`
- [ ] Confirm the signed bundle exists at `android/app/build/outputs/bundle/release/app-release.aab`
- [ ] Confirm the version and package name are correct
- [ ] Confirm no test data is exposed in screenshots or listing copy

## Google Play

- [ ] Upload `app-release.aab`
- [ ] Fill the store listing from `google-play.ar.md` or `google-play.en.md`
- [ ] Use the screenshot order from `final-upload-pack.md`
- [ ] Complete content rating and data safety
- [ ] Add screenshots and feature graphic if required

## App Store

- [ ] Fill App Store metadata from `app-store.ar.md` or `app-store.en.md`
- [ ] Prepare the IPA from macOS/Xcode
- [ ] Use the screenshot order from `final-upload-pack.md`
- [ ] Add screenshots for the target device sizes
- [ ] Complete App Privacy details

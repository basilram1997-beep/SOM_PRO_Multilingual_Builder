هذه السياسة تشرح كيف نتعامل مع بيانات المدارس داخل SOM PRO.

آخر تحديث: 23 أغسطس 2026 التطبيق: SOM PRO النطاق: إدارة شؤون المدرسة

1. النطاق

تنطبق هذه السياسة على جميع البيانات التي تُنشأ أو تُدخل أو تُرفع أو تُخزن داخل SOM PRO نيابةً عن مدرسة أو جهة تعليمية أو سلطة تعليمية.

2. ملكية البيانات

جميع بيانات المدرسة تبقى ملكًا للمدرسة أو للجهة التعليمية، وليس للمورّد. يقوم SOM PRO بمعالجة هذه البيانات فقط لتقديم الخدمة التعليمية المتفق عليها.

  • لا نبيع بيانات المدرسة.
  • لا نعيد استخدام البيانات لأغراض تسويقية.
  • لا نشارك البيانات مع أطراف ثالثة افتراضيًا.
  • لا نحتفظ بالبيانات بعد انتهاء العقد إلا إذا وُجد أساس قانوني أو تعاقدي.

3. كيفية استخدام البيانات

تُستخدم البيانات فقط لتشغيل الميزات المدرسية المتفق عليها مثل الدروس والواجبات والامتحانات والحضور والسلوك والدرجات والشهادات والجداول والتقارير.

4. التصدير والحذف

قد تتضمن المنصة إجراءات تصدير أو حذف للبيانات على مستوى المدرسة. هذه الإجراءات تكون محمية بالصلاحيات، ومُسجّلة، وتتطلب تأكيدًا واضحًا قبل التنفيذ.

  • التصدير والحذف يجب أن يكونا محدودين بالصلاحيات.
  • يجب تسجيل العملية في سجلات التدقيق.
  • ملفات التصدير لا تكون عامة.
  • قد يُستخدم الإخفاء أو التفريغ بدل الحذف النهائي إذا تطلبت السياسة ذلك.

5. التخزين المحلي

لا يجب تخزين البيانات المدرسية الحساسة محليًا على جهاز سطح المكتب أو داخل تخزين المتصفح، إلا في الحالات غير الحساسة مثل تفضيلات الواجهة أو بيانات التمهيد المسموح بها.

6. الأطراف الثالثة

لا يُسمح لأي خدمة خارجية باستقبال بيانات الطلاب إلا إذا كانت معتمدة ومذكورة بشكل صريح في إعدادات النظام ووثائق المشروع.

7. صور وفيديو وصوت الطلاب

تسجيل أو التقاط صور أو فيديو أو صوت للطلاب معطّل افتراضيًا وليس جزءًا من النسخة الحالية من التطبيق.

8. الأمان

نتخذ إجراءات معقولة لحماية البيانات وفق صلاحيات المدرسة، ونتعامل مع البيانات الحساسة بحذر ضمن قواعد العزل والتشغيل الخاصة بالنظام.
